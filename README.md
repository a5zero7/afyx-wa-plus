# Afyx WA Plus

Local-first privacy, export, translation, and customization tools for WhatsApp Web. Independent of and not endorsed by WhatsApp LLC or Meta Platforms, Inc.

## Development

Install dependencies with `pnpm install`, then use `pnpm dev` for Chromium or `pnpm dev:firefox` for Firefox. The current implementation is Phase 0/1 scaffolding; feature progress is tracked in `docs/FEATURE_STATUS.md`.
